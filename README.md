# WeerSport

Nederlandse webapp voor het beste moment om buiten te sporten. Deze repository bevat Phase 01: het goedgekeurde ontwerpsysteem en de responsive homepage.

## Starten

```bash
npm install
npm run dev
```

De site staat daarna op `http://localhost:3000`.

## Controles

```bash
npm run check
npm run lint
npm run build
```

## Scope van deze fase

- Manrope, WeerSport-kleuren en de goedgekeurde merk- en sporticonen uit Figma `BXos6MSVR6AxSpO3a7sLb6`.
- Homepage voor desktop en mobiel, inclusief planner, 24 sporten, voorbeeldscore, uurcurve, UV-voorbeeld en navigatie.
- Breakpoints rond 320, 390, 768, 1024 en 1440 px.
- Het scorevoorbeeld is fictief en start geen analyse.

Authenticatie, live weer, quota, Mollie en AdSense horen bij latere fases.
